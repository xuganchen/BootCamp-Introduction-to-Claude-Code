# Step 3. Analysis and report

One prompt, one turn, no follow-ups. Nothing here parses anything; this step only
uses the panel.

```
ultracode
Based on the 2018-2026 data in output/panel/bdc_quarter.csv and
output/panel/bdc_quarter_investment.csv, produce an industry report on this
portfolio. Write the code to analysis and output everything to output/analysis.
The analysis report style follows the documents in reference, and should be in
both .docx and .pdf, with figures and tables. It should at least include sample
coverage, summary statistics, time series, deal terms, and cross-section. Be
specific about percentages and periods. Every figure and table states the period
it covers and the share of rows it is computed on.
```

`reference/` here is a folder of published research reports whose style the report
copies. They are third-party and not redistributed; see `../README.md`.
